Welcome to ShadeSphere

Your personal color space to save, manage, and explore colors with ease

ShadeSphere is a powerful and intuitive color management application that helps you organize and manage your color palettes efficiently. Whether you're a designer, developer, or color enthusiast, ShadeSphere provides the tools you need to work with colors effectively.

Help / FAQ

Check if the sidebar is locked. Use Shift + Alt + X to toggle the lock state.

Verify that:

  • Your browser supports localStorage
  • You're not in incognito/private browsing mode
  • Your browser's storage isn't full

Ensure that:

  • Auto Grid View is enabled in settings
  • Screen width is ≥ 720px for grid view
  • You haven't manually overridden the layout

Make sure that:

  • The browser tab is focused
  • You're pressing the correct key combination
  • No other application is capturing the shortcuts

Layout Options

Grid View

Display colors in a responsive grid layout, perfect for larger screens and quick color browsing.

List View

Show colors in a vertical list, ideal for mobile devices and detailed color information.

Auto Grid Feature

Automatically switches between grid and list views based on screen width (720px breakpoint). This can be manually overridden through the layout controls.

How to Use

Color Interactions

Single Click

Click once on any color to copy its code to clipboard

Double Click

Double click to open the color editor with options to copy and edit

Right Click

Opens a context menu with options to Select, Select All, or Edit

Color Selection

Use Select or Select All to manage multiple colors at once. Selected colors can be deleted as a group.

Color Editor

The editor modal provides options to:

  • Copy the color code
  • Edit the color value
  • Preview changes in real-time
  • Save modifications

Search Features

Smart Color Search

Search for colors using:

  • Color names (e.g., "red", "blue")
  • HEX codes (e.g., "#ff0000")
  • RGB values (e.g., "rgb(255,0,0)")

Live Suggestions

As you type in the search box:

  • Matching colors appear as suggestions
  • Each suggestion shows a color preview
  • Click any suggestion to highlight that color in your list

Search Tips

  • Searches are case-insensitive
  • Partial matches are supported
  • Use keyboard arrows to navigate suggestions
  • Press Enter to select highlighted suggestion
  • Press Escape to clear search

Trash Bin

Color Recovery System

Colors aren't permanently deleted - they move to the Trash Bin first, allowing you to recover them if needed.

Important Points

  • Trash capacity: 30 colors maximum
  • When trash is full, the trash icon shows "Full" in red
  • Attempting to delete colors when trash is full prompts a warning
  • Options for each color in trash:
    • Restore - Moves color back to your saved colors
    • Delete Permanently - Removes color completely

Delete All: When you click Delete All, a confirmation shows how many colors will move to Trash and how many will be permanently deleted based on available Trash space. Trash capacity is 30 colors. Only available space is used; the rest are permanently deleted.

Resize Feature

Adjustable View

The color list container can be resized to fit your needs:

  • Click the resize icon in the sidebar to enable resize mode
  • Drag from the bottom-right corner to adjust size
  • Container maintains minimum dimensions for usability
  • Size adjustments persist until you modify them again

Resize feature is disabled in fullscreen mode and on mobile devices

Settings

Auto Grid View

When enabled, automatically switches between grid and list layouts based on screen width:

  • Screen width ≥ 720px: Grid View
  • Screen width < 720px: List View

Note: Manual layout changes will disable Auto Grid View. Re-enable it in settings to restore automatic behavior.

Theme Settings

Manual Theme Control

Switch between Dark and Light themes manually using:

  • Theme toggle button in the top bar
  • Keyboard shortcut: Shift + Alt + D

Auto Theme Mode

When enabled, automatically switches themes based on your selected time range.

  • Enable Auto Mode from Settings → Auto Theme Mode toggle.
  • Click the chevron icon next to the toggle to expand the dropdown.
  • Edit the custom time range (From → To) inside the dropdown.
  • Editing is only allowed when Auto Mode is OFF. When ON, inputs are disabled.
  • The description under the option updates dynamically to show the selected range (e.g., “Dark Mode active from 8:00 PM to 9:00 AM”).
  • The dropdown lives inside the Auto Theme Mode option, directly under the toggle.

Note: Manually changing the theme (using the top bar button or shortcut) turns Auto Theme Mode OFF automatically.
